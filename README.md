🔍 Object Detector

📌 Project Overview

This project is an Object Detection application developed using Python. It detects and identifies objects present in an image or video and displays bounding boxes around the detected objects.

The project demonstrates how Computer Vision and Deep Learning can be used to automatically recognize objects.

🎯 Objectives

- Detect objects from images or video.
- Identify the objects present in the input.
- Draw bounding boxes around detected objects.
- Display the detected object's name and confidence score.
- Understand the basic implementation of object detection using Python.

🛠️ Technologies Used

- Python
- OpenCV
- YOLO / Object Detection Model
- VS Code
- Git & GitHub

⚙️ Installation

1. Clone the repository

git clone https://github.com/your-username/object-detector.git

2. Open the project

cd object-detector

3. Install the required libraries

pip install -r requirements.txt

If you don't have a "requirements.txt" file, install the required packages manually:

pip install opencv-python

▶️ How to Run

Run the Python file from VS Code terminal:

python main.py

Then provide the required image/video input according to the implementation.
