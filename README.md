## Object Detector

 ## Project Overview

This project is an Object Detection application developed using Python. It detects and identifies objects present in an image or video and displays bounding boxes around the detected objects.

The project demonstrates how Computer Vision and Deep Learning can be used to automatically recognize objects.

## Objectives

- Detect objects from images or video.
- Identify the objects present in the input.
- Draw bounding boxes around detected objects.
- Display the detected object's name and confidence score.
- Understand the basic implementation of object detection using Python.

## Technologies Used

- Python
- VS Code
- Git & GitHub

## How It Works

Input Image / Video
        ↓
Object Detection Model
        ↓
Image Processing
        ↓
Object Identification
        ↓
Bounding Boxes + Labels
        ↓
Detected Output

## Features

- Real-time/object detection
- Object identification
- Bounding box visualization
- Confidence score display
- Easy to run using Python
